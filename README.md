# НАШЯК — безкоштовна вебгра (PWA)

## Що вже працює
- Ігрове поле з категоріями та питаннями за бали
- Редактор категорій, питань, відповідей і посилань на медіа
- Гравці, рахунок, ручне нарахування/зняття балів
- Кнопки гравців: перше натискання фіксується на цьому пристрої
- Фінальна категорія, питання, ставки та підрахунок
- Збереження у браузері, експорт та імпорт набору гри
- Адаптивний інтерфейс і PWA-режим для встановлення

## Важливе обмеження першої версії
Це локальна версія: гра і натискання кнопок працюють у межах одного браузера/пристрою. Для справжньої гри з окремими телефонами гравців треба додати онлайн-базу даних і синхронізацію в реальному часі (наприклад, Supabase або Firebase).

## Як відкрити
Для швидкої перевірки відкрийте `index.html` у браузері. Для встановлення як PWA потрібен сайт через HTTPS (наприклад, GitHub Pages). Інструкцію для публікації дивіться нижче.

## Безкоштовне розміщення через GitHub Pages
1. Увійдіть на https://github.com/ та створіть новий репозиторій, наприклад `nashyак`.
2. Завантажте в нього всі файли з цієї папки (не сам ZIP).
3. Відкрийте Settings → Pages.
4. У розділі Build and deployment оберіть Deploy from a branch, гілку `main` і папку `/ (root)`, натисніть Save.
5. Дочекайтеся посилання на сайт у розділі Pages.
6. Відкрийте це посилання на телефоні. Android: меню браузера → Install app / Add to Home screen. iPhone: Safari → Share → Add to Home Screen.

GitHub Pages безкоштовний для публічних репозиторіїв. Не завантажуйте приватні дані чи паролі у файли проєкту.
